## Proposito

Las politicas convierten principios juridicos, tecnicos, comerciales y de seguridad en reglas verificables para implementacion.

## Reglas

- Toda politica debe tener estado documental.
- Toda politica debe tener responsable.
- Toda politica debe declarar alcance.
- Toda politica critica debe distinguir reglas deterministicas de reglas asistidas por IA.
- Toda politica que bloquee una respuesta debe describir el comportamiento esperado.
